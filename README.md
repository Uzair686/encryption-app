# Encryption App

A small web-based encryption app built with HTML, CSS, and JavaScript.

## Features
- Encryption utility interface
- Client-side JavaScript logic
- Lightweight project structure

## Run locally
1. Open `index.html` in a browser, or
2. Serve the folder with a simple local server.

## Project files
- `index.html` – app structure
- `styles.css` – styling
- `script.js` – encryption logic
- `test.js` – tests / checks
